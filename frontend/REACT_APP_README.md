# BUCKET JEJU

버킷제주 게스트하우스 투숙객을 위한 근처 장소 발견 및 Join 커뮤니티 웹 데모입니다.

- 배포 주소: https://bucket-jeju-join.ep01-sleepwar.chatgpt.site
- 사용자 식별: 실명·이메일 없이 닉네임만 사용
- 장소 범위: 버킷제주 고정 위치 기준 반경 2km
- 프로필: 활동 키워드 약 300개 중 테스트 단계에서는 상위 5개 표시

## 버전 기록

### v1 — 기초 배포용

- 제주 감성의 반응형 기본 UI
- 홈, 근처 발견, Join, 프로필 화면 구성
- 버킷제주 위치 중심 지도 및 주변 장소 예시
- Join 카드와 참여 버튼의 기본 동작 구현

### v2 — 합성 시드 데이터 및 한글 화면 정상화

- 가상 투숙객 30명 생성
- 2026년 8월 1일부터 15일까지 15일간 Join 60건 적용
- 매일 4개의 Join 일정 배치
- 산책, 식사, 운동, 사진, 카페, 자전거, 친목, 여행, 요가 등 다양한 키워드 분배
- Join 필터 및 참여/취소 동작 연결
- 합성 데이터임을 Join 화면과 데이터 문서에 명시
- 깨진 한글과 화면 코드를 정상화
- 지도 화면에 버킷제주 기준 반경 2km 안내 표시

## 합성 데이터 안내

현재 화면의 투숙객 닉네임, 객실·침대, 투숙 기간, Join 일정은 개발 및 시연을 위해 임의 생성한 합성 데이터입니다. 실제 투숙객이나 실제 예약 정보를 나타내지 않습니다.
