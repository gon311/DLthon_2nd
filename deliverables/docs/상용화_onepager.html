A 상용화 준비 — 우선순위 체크리스트

  • 필수데이터 파이프라인 — POI 수집·검수·최신화(영업시간·사진·연락처), 코드 하드코딩(21곳)→DB/API 기반, 폐업·신규 자동 갱신
  • 필수독립 인증 · 법적 준비 — ChatGPT 로그인 탈피(카카오·구글·이메일), 개인정보처리방침·이용약관·위치정보 동의
  • 필수정식 인프라 — chatgpt.site(데모)→자체 도메인+Cloudflare 정식 배포, CI/CD·D1 백업·모니터링·에러추적
  • 중요안전 · 신뢰 장치 — Join(낯선 사람 만남) 신고·차단·평점, 노쇼 방지, 리뷰 모더레이션
  • 중요미완성 기능 마무리 — Join 참여·취소 DB 저장·정원·알림, AI질문 RAG 연결·출처표시, 방문객 리뷰(방문 인증)
  • 다음운영 · 품질 — 관리자 대시보드, 애널리틱스, E2E 테스트, 보안(키관리·봇방지), 다국어 품질·PWA
가장 큰 관문 4가지: ① 진짜 데이터 파이프라인 ② 독립 인증/법적 준비 ③ 정식 인프라 ④ 안전장치. 수익모델·운영툴은 그다음.

B 광고 · 수익 모델

  • 지역 스폰서 플레이스 ★가장 적합
    2km 내 업체를 추천/스폰서로 지도·상단 노출. 월정액 또는 CPC. 초지역 타겟이라 전환·단가 높음
  • 예약 어필리에이트
    마라도·가파도 배편, 투어·액티비티, 숙박 예약 연동 → 예약당 수수료(Klook·마이리얼트립·야놀자 등)
  • 제휴 쿠폰·프로모션
    앱 전용 할인쿠폰 사용 건당 수수료. 게스트하우스 운영이라 로컬 업체 섭외가 강점
  • 범용 배너(AdSense/AdMob)
    트래픽 커진 뒤 보조 수단. 단가 낮고 UX 저하 — 초기엔 비추
광고·스폰서는 "광고/스폰서" 명시 의무(전자상거래법), 과도한 광고로 UX 훼손 금지, 맞춤광고 시 개인정보 동의 필요.

C 내일 팀에서 정할 것

  • 데이터 소스·수집 방식 (kakao API 키·예산)
  • 인증 방식(어느 소셜) + 호스팅 이전 시점
  • 광고 1순위 스폰서 플레이스 파일럿 여부 + 제휴 업체 후보
  • MVP 상용 범위·출시 일정
